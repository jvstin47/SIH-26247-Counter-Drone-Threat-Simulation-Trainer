# SIH Pitch

## One-line value proposition
AID-C2S converts expensive, weather-dependent repetition into a lightweight, measurable and repeatable synthetic training workflow.

## What is different
1. Seeded Scenario DNA creates many variations without hand-authoring each run.
2. Deterministic scoring and event logs make the training process auditable.
3. AAR turns raw actions into coaching and historical trends.
4. Adaptive difficulty changes the next training profile using measured performance.
5. Browser/PWA delivery keeps the core system deployable without specialist hardware.
6. AI is an optional perception/instructor layer rather than a hidden source of truth.
