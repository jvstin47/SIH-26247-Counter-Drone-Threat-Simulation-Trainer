# Suggested SIH demo — 4 to 5 minutes

1. **Command (30 s):** introduce the synthetic, offline-first trainer and show real runtime capability status.
2. **Launch SIH Demo (15 s):** start the seeded showcase scenario.
3. **Live training (90 s):** start simulation, select a contact, inspect multi-source confidence, use track focus and local evidence assist, set a classification/confidence and submit an abstract decision.
4. **Uncertainty and tracking (30 s):** point out synthetic sensor degradation, track history and possible low-confidence/lost tracks.
5. **Finish + AAR (45 s):** explain the deterministic score breakdown and event timeline.
6. **Replay (30 s):** seek to an event, step frames/events, change playback speed, export JSON.
7. **Scenario Lab (30 s):** vary visibility/health/entity count, save a new seed, and show import/export.
8. **Analytics/System (30 s):** show the saved-session trend/profile aggregate and local backup/offline status.

Reset Demo returns to the command screen and starts the fixed showcase seed again. All media clips are local generated synthetic assets. For the final presentation, run the browser walkthrough and production build on the target PC first.
