# 4-Minute SIH Demo Script

1. Command dashboard: explain the problem and the local-first architecture.
2. Start Demo Session: show the 3D synthetic environment, radar and runtime indicators.
3. Acquire a contact and classify it with confidence.
4. Select an abstract training response and finish the scenario.
5. Open AAR: show score breakdown, timeline and replay.
6. Click ADAPTIVE NEXT: show that the next Scenario DNA changes according to measured performance.
7. Open Scenario Lab: change visibility, sensor health and ambiguity, then generate the same scenario again with the same seed to demonstrate reproducibility.
