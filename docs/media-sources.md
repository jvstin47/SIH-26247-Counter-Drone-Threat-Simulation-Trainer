# Media assets and attribution

All clips in `public/media/` were generated locally for AID-C2S V5 from procedural grayscale sensor/evidence graphics. They contain synthetic tracking boxes, moving contact markers, scan lines, local timestamp labels and fictional channel readouts. No third-party footage, stock clip, YouTube download, real sensor recording, or external network stream is embedded.
